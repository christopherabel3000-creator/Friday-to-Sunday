Privacy policy

Friday to Sunday, by playbyear. Last updated November 13, 2026.

Friday to Sunday is a football coaching game you play on your own. It has no accounts, no ads, no analytics and no tracking. This page explains the little information the game handles and where it goes.

What stays on your device

Your game is saved on your phone or computer: in the browser's storage on the website, and in the app's own storage and Documents folder in the iPhone app. That includes everything in your career, such as the names you give your coach and your schools, plus settings like whether sound is on. None of it is sent anywhere unless you use a cloud save. Deleting the app, or clearing the website's data in your browser, deletes it.

Cloud saves, if you use them

Cloud saves are optional. When you tap Save to the cloud, the game sends a copy of your saved game to an online database run with Google's Firebase service. The copy is stored with:

  • your 12-character cloud save code, which the game makes up at random,
  • the time of the save, and
  • a random code for the device that saved it, made up by the game and kept on that device, so the game can tell when a save was changed on another device.

Nothing in a cloud save identifies you, unless you type something that does, such as your real name as your coach's name. Anyone who has your cloud save code can load or replace that save, so keep the code private, like a password. Nobody can list or browse the saves; a save can only be found with its code.

When a cloud save is sent or loaded, Google receives your device's internet address as part of the connection, as any website does. Google handles it under its own terms as a service provider; the game doesn't keep or use it. You can read Firebase's privacy information.

Cloud saves are kept so you can load them later. To have yours deleted, contact me with its code (see below) and I'll remove it.

Save codes and files

A save code or save file is your game written out as text. The game only makes one when you ask, and it stays wherever you put it, such as your notes or email. It isn't sent anywhere by the game.

Children

The game isn't aimed at children under 13 and doesn't knowingly collect personal information from them. It never asks for any.

Changes

If the game ever handles information differently, this page will be updated first, with a new date at the top.

Contact

Questions, or a cloud save you'd like deleted: open an issue on the game's GitHub page. Please don't post your cloud save code there publicly; say you have one to delete and I'll arrange a private way to send it.
