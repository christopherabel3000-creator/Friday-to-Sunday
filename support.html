Support

Friday to Sunday, by playbyear.

Friday to Sunday is a single-player football coaching career. Start as the head coach of a tiny high school, call every play, run practice and build the program, then climb to bigger schools, college and the pros. It works fully with VoiceOver and other screen readers.

Get help or send feedback

Use the contact form for bug reports, questions and ideas. You don't need an account. Add your email address if you'd like a reply. For a bug, it helps to say what you were doing, which screen you were on, and whether you use VoiceOver.

Common questions

Is my game saved?

Yes. The game saves on its own as you play, on your device. In the iPhone app it's also kept as a file in the app's own storage, which iOS doesn't clear. Deleting the app deletes the save, so make a cloud save or a save code first.

How do I move my game to another device?

From the main menu, open Cloud saves and save codes. Tap Save to the cloud to get a 12-character code, then enter that code on the other device. You can also copy a save code (your whole game as text) and paste it in on the other device, or save it as a file. The website and the app can load each other's saves.

I lost my cloud save code.

The game shows it on the Cloud saves and save codes screen of the device that made it. Nobody else can look it up, not even the developer, because saves can't be listed or searched.

Does it need the internet?

No. Everything works offline except cloud saves.

Does it have ads or track me?

No ads, no accounts and no tracking. See the privacy policy.

Is it a real league?

No. Every school, conference and pro team is made up, and you can rename any of them from the main menu. The rules follow the real high school, college and pro rules as closely as the game can.
